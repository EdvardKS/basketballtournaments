1

Encender la aplicación

⚡
  1. El admin arranca la web en su servidor.
    1. Indica si quiere datos de ejemplo o empezar con la base vacía.
    2. Define un usuario administrador inicial (nombre + contraseña).
  2. La aplicación prepara la base de datos sola al arrancar.
    1. Crea las tablas necesarias si faltan.
    2. Mete los datos de ejemplo si así se pidió.
    3. Garantiza que el usuario administrador existe.
  3. Cuando todo está listo, la web abre en http://servidor:4322.
2

Iniciar sesión y recuperar contraseña

🔐
  1. Cualquier persona entra a /login.
    1. Puede escribir su móvil, su email o su nombre de usuario. Los tres valen.
    2. Si los datos coinciden, entra a su panel.
  2. Si olvida la contraseña usa /recover:
    1. Primero resuelve una pregunta sencilla (suma corta) para demostrar que no es un robot.
    2. Introduce los tres datos de su cuenta: móvil, email y usuario.
    3. Si los tres coinciden con la misma persona, la web le deja elegir una contraseña nueva.
    4. Si NO coinciden, le pide escribir a developerweks@gmail.com para verificar identidad manualmente.
  3. Una vez dentro:
    1. Desaparece el menú público.
    2. Aparece un menú con sólo las acciones de su rol.
    3. Los jugadores no ven menú: su panel ya tiene un botón «Salir».
3

Crear un torneo nuevo

🏆
  1. El admin entra a su panel y pulsa «Crear torneo».
    1. Sólo puede crear uno cuando no hay otro «en marcha».
    2. Si ya hay uno activo la web se lo impide hasta cerrarlo.
  2. Rellena el formulario:
    1. Nombre, lugar, descripción y reglas.
    2. Fechas clave:
      • Inicio de inscripciones: cuándo abren al público.
      • Inicio del draft: cuándo empiezan los capitanes a elegir.
      • Fin del draft: cuándo se cierra la elección.
      • Día del torneo: la fecha del partido.
  3. Al guardar, el torneo queda en fase «Inscripciones abiertas» si las fechas ya están dentro del periodo.
  4. El botón «+ Nuevo torneo» desaparece. El admin gestiona ese torneo desde el panel.
4

Inscripciones (fase «open»)

📝
  1. Personas sin cuenta (vienen de la calle):
    1. Ven el botón «Inscribirme» en la página del torneo.
    2. Crean cuenta (nombre, móvil, email, edad, foto, RGPD).
    3. La web los inscribe automáticamente al terminar.
  2. Personas con cuenta que aún no se han inscrito:
    1. Ven un botón azul: «Inscríbete a este torneo».
    2. Con un clic quedan dentro.
  3. El admin puede dar de alta a alguien manualmente:
    1. Pestaña «Inscripciones» → «+ Alta de jugador».
    2. Nombre, móvil, email, edad, posición. Contraseña inicial: 123123123.
    3. Opcional: marcar «Capitán» y poner nombre de equipo en el mismo paso.
  4. El admin no puede inscribirse a sí mismo. La aplicación lo bloquea: él organiza, no juega.
  5. Cada inscripción, alta o baja:
    1. Se guarda en la base de datos.
    2. Se reescribe un CSV de seguridad con todos los inscritos del torneo (abrible en Excel).
5

Designar capitanes

⭐
  1. El admin entra a la card de un jugador inscrito.
    1. Marca el check «Capitán de este torneo».
    2. Escribe el nombre del equipo (se autogenera si lo deja vacío).
  2. La aplicación, por detrás:
    1. Crea el equipo con ese nombre.
    2. Mete al capitán como primer miembro de la plantilla.
    3. Sube su rol de «jugador» a «capitán».
  3. Si el admin quita el rol de capitán (sólo antes del draft):
    1. La web pide confirmación dos veces.
    2. Muestra logo, nombre, WhatsApp y descripción del equipo que se va a borrar.
    3. Al confirmar, elimina el equipo entero. El jugador vuelve a su rol normal.
⚠️ Importante: una vez empieza el draft, el admin ya no puede tocar capitanías.
6

Editar el equipo (capitán)

🎨
  1. El capitán entra a su panel y ve la sección «Mi equipo».
  2. Puede:
    1. Subir un logo (la web lo recorta a 200 px).
    2. Editar nombre del equipo, descripción y enlace de WhatsApp.
  3. Tiene hasta el día anterior al partido para tocar estos campos.
  4. Desde la víspera la web los bloquea. El admin sí puede tocarlos por si hay una urgencia.
7

Empezar el draft (paso de «open» a «draft»)

🎯
  1. Cuando llega la fecha de «Inicio del draft»:
    1. La app pasa el torneo automáticamente a «draft» en cuanto alguien lo visita.
    2. Sortea el orden inicial de los capitanes.
    3. Marca el draft como «en curso».
  2. Desde ese instante el admin no puede tocar capitanías.
  3. La página pública del torneo muestra «DRAFT EN VIVO».
8

Elegir jugadores (draft)

🏀
  1. Cada capitán entra a su panel y, cuando le toca, pulsa al jugador que quiere fichar.
  2. La app rota turnos entre capitanes ronda tras ronda.
    1. En cada ronda baraja el orden: ningún capitán repite la misma posición que en rondas anteriores.
    2. Si en una ronda alguien fue el 2º, en la siguiente no podrá serlo otra vez.
  3. El draft continúa hasta repartir a todos los inscritos.
    1. Con 53 jugadores y 6 capitanes, unos equipos quedan con 8 y otros con 9. Es normal.
    2. Cuando se acaba la pool, la app cierra el draft sola. No hay que pulsar nada.
  4. Al cerrarse, la app hace todo esto automáticamente:
    1. Genera los grupos (un grupo por cada 4 equipos, equilibrado).
    2. Genera el calendario con la hora de cada partido, según el día, las canchas y la duración.
    3. Confirma las horas como publicadas (los jugadores ya las ven).
    4. El torneo pasa a fase «Grupos publicados».
💡 Resultado: al final del draft cada equipo tiene su plantilla completa y la web ya muestra el calendario con horas en la página pública.
9

Traspasar la capitanía

🔄
  1. Una vez empezó el draft, el admin ya no puede quitar capitanes.
  2. Pero el capitán que ya haya elegido al menos a un jugador puede pasarle el rol a un miembro de su equipo:
    1. Entra a «Traspasar capitanía» en su panel.
    2. Elige al nuevo capitán de la lista de su plantilla.
    3. Confirma dos veces.
  3. El equipo se queda intacto: logo, nombre, WhatsApp y plantilla siguen igual. Sólo cambia quién aparece como capitán visible. El ex-capitán se queda como jugador normal del equipo.
10

El día del torneo (paso de «setup» a «active»)

🚀
  1. Cuando llega la fecha del partido, la app cambia el torneo automáticamente a «TORNEO EN JUEGO» en cuanto alguien entra a verlo.
  2. La home pública lo refleja con el banner correspondiente.
  3. Aparece la lista completa de partidos con sus horas.
  4. Los partidos están como «pendientes» hasta que el admin los arranque (eso ya es la fase post-partido, fuera de este flujo por ahora).
11

Copia de seguridad permanente (CSV)

💾
  1. Por cada cambio en las inscripciones, la app reescribe un fichero .csv con TODOS los inscritos de ese torneo.
  2. Se guarda en backend/data/csv/<fecha-del-partido>.csv y se abre con Excel o LibreOffice.
  3. Contiene, fila a fila: cuándo se inscribió, datos del torneo, datos del jugador (nombre, móvil, email, edad, posición, stats, RGPD) y, si es capitán, su equipo.
  4. El CSV se actualiza al instante en cada uno de estos eventos:
    1. Alguien se inscribe.
    2. Alguien se da de baja.
    3. El admin nombra o quita un capitán.
    4. El admin da de alta o elimina un jugador del torneo.
    5. El admin edita los datos de un jugador.
    6. Un capitán traspasa su rol.
🛟 Seguro de vida: si la aplicación se cayera, con este CSV se reconstruyen las inscripciones aunque la base de datos se pierda.

Resumen visual de las fases

🗺️
Upcoming
próximo · nadie ve nada todavía
Open
inscripciones abiertas
Draft
capitanes eligen plantilla
Setup
grupos + horas publicados
Active
día del partido

Las transiciones entre fases las dispara la fecha. La app no necesita que nadie pulse nada: si pasa la fecha de inicio del draft, lo enciende. Si pasa el día del torneo, lo pone «en juego». El admin puede acelerar manualmente si quiere.

Quién ve qué

👥

Anónimo

  • Home, torneo, galería, bases.
  • Botones para inscribirse / login / registrarse.

Jugador

  • Su carta tipo FIFA con stats.
  • Torneo activo + botón Salir.

Capitán

  • Gestión del equipo (logo, nombre, WhatsApp).
  • Draft en vivo cuando toca.
  • Traspaso de capitanía si ya picó.

Admin

  • Pestañas: Inscripciones, Draft, Jugadores, Grupos, Eliminatorias, Partidos, Resultados, Resumen, Configuración.
  • Edición del torneo inline en la propia pestaña.
14

Cosas que la aplicación impide a propósito

🛡️
  1. Tener dos torneos en marcha a la vez.
  2. Que el admin se apunte como jugador.
  3. Tocar capitanes una vez empezado el draft.
  4. Que un capitán edite su equipo desde la víspera del partido.
  5. Inscribirse fuera del periodo de inscripción / draft.
  6. Usar un móvil ya registrado para una cuenta nueva.

Cada una de estas reglas devuelve un mensaje claro a quien intenta saltársela.
